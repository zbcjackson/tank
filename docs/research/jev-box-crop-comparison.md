# Jev Box整窗、区域裁剪与Gemini定位对照

## 结论

同样的4张历史实验窗口图（TextEdit/Calculator各2张），比较Jev1.14.0与
OpenRouter的google/gemini-3.8-flash。6个合成控制全部通过后，64个主问题全部
运行，每题一次，无重试、无点击。结构解析全部成功；Jev两种表示和Gemini整窗
数量各16/16正确，Gemini裁剪15/16（一次多个对齐按钮误判唯一）。唯一目标
中心按预声明AX内部区域评分：

- Jev：整窗5/8，区域裁剪8/8；主问题复合通过分别13/16、16/16。
- Gemini：整窗7/8，区域裁剪8/8；主问题复合通过分别15/16、15/16。

裁剪后唯一中心两模型均8/8，但Gemini的数量误判使复合评分仍为15/16；Jev裁剪
为16/16。不能只看唯一中心而忽略误判唯一的风险。

这组已见图支持“图片表示影响定位，裁剪对Jev有帮助”，不能认定Jev视觉强于
可替换视觉模型，也不能推广为所有视觉任务的排名。Gemini整窗也有失败，裁剪
结果需连同具体目标/布局解释；本轮没有验证点击效果、自动裁剪策略或完整路由。

Gemini官方原生示例常用YX顺序，本轮通过非对称色块控制验证自定义XY契约，
