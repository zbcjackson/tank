# V/JT正式确认设计

## 目标和边界

承接[主计划](../active/computer-use-jev-vision.md)及
[校准结果](../../research/jev-calibration-route.md)。本任务基线73191da4，独立审查
最多三轮；不沿用已结案校准任务的轮数。交付可复算的分层配对估计、全部门联合
功效/精度敏感性、明确的N准入判断及新任务生成/隔离工件。原始模型结果、旧
协议及归档保持；只做离线设计和无模型结构校验，不启动收费确认或切换默认。

范围仍为两款固定原版应用的列表→编辑→返回、四行数据和完整业务验收。新seed
表示新数据任务，不冒称新布局或新应用。两启动条件与V/JT留在同一seed簇，
保持产品/场景分层；采用门和速度主终点不因结果而降低。

## 步骤

1. 校验校准输入/冻结/补充协议的hash，提取20正例和4负例簇；核对分层、两条件
   与四项执行完整配对，包含全部失败的120秒封顶规则和负例单列。
2. 计算既定分层配对BCa速度诊断；零二项事件的退化区间显式未定义。对正式
   区间方法提出可审查的候选：保留原BCa方案的区别，推导适用于独立、有界、
   分层非同分布seed的保守区间，不把IID二项公式直接套在相关重复上。
3. 在平衡分配候选N上同时核质量绝对/差异、主要族、恢复绝对/差异、意外业务
   动作、速度及安全约束；给每门及全部门联合功效、Monte Carlo不确定性和
   精度。纳入非零失误、相关性、时间离散及上界敏感性，取整后逐个复算。
   乐观假设不得充当真实失误率；若保守证据不足，正式N保持null并给出确切缺口。
4. 冻结版本化候选协议/生成器和新的任务bank；与全部校准seed/目标数据hash
   分离，分配和arm顺序预定，目标/完整列表/身份约束及源保持。若正式N未准入，
   bank明确不是已准入确认集、不形成可执行模型排程，不以标题变化伪造布局。
5. 独立数学/结构复核、归档全部脚本/结果/失败、旧档hash核验及实际凭据扫描；
   使用canvas技能提供实际计算结果的筛选面板。完整适用验证后交code-reviewer
   review-and-refactor；无问题即停止，结案并将下一阶段明确交回主计划。

## Tests

- 先验证统计原语的手算/解析边界、0/全失败、二项退化、负例不混入速度、失败
  时间封顶及同seed两条件不拆簇；校准配对/分层缺失应拒绝。
- 各强制门分别构造单门失败，联合判定均拒绝；低于80%或Monte Carlo区间不足
  不准入，平衡取整不继承前一个N的功效。
- 生成器确定性、已知目标身份、分层/冷暖/arm配平、与旧任务不交叠、数据/目标
  一致、无模型客户端/凭据读取。任务bank不得在N未准入时冒充执行计划。
- 正交算法核算零事件边界、条件功效及关键仿真点；不复制同一实现当独立证据。
- 面板数值与归档JSON一致，tsc通过；原文书/新工件通过docs与逐成员hash检查。
