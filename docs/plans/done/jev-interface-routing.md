# 界面证据与自然视觉接管

## 目标与取舍

承接[主计划](../active/computer-use-jev-vision.md)。按用户澄清，以控件/可访问名称/文字/上下文、
布局/图标/颜色与结果核验能力选择路线；存在可区分结构信息先Jev，不成立再视觉。
当前生产ActionAdmissionSelector已具备主路径，本片先更新现行设计及验证顺序，不
新增App分类器、阈值或策略，不改变默认。视觉必要性以当前协议缺少所需界面证据
判断，不要求先证明任何文字模型绝对无法推断。

已完成正例及反例不继续扩样。优先一个结构缺空间信息、图片能区分的真实界面任务，
按自然路由完成；后续再按图标语义、颜色、命名上下文等特征选择少量任务，不机械
补旧六项。生产通道无合法候选或无法核验时，保留真实资格缺口，不伪造补强。

## 步骤

1. 更新[现行设计](../../design/computer-use.md)、主计划/索引/backlog，明确逐步路线、
   Jev所选动作的准入、视觉返回与硬停止，以及当前仅支持已有候选的执行范围。
2. 使用原版sqlite-web 0.8.1、两条公开合成记录和生产Runner/DOM通道。唯一任务从
   work_items内容页开始，只点击左侧导航栏内work_items链接进入表结构页，禁止使用
   顶部同名面包屑、Structure页签或修改数据。两同名链接的role/label/value/祖先/
   effect语义相同，文字投影无位置，截图明确呈现左右区域。候选顺序仍可见，不声称
   排序绝不能作为位置猜测；本片检验宿主对空间目标的可区分性与自然图片执行路径。
3. 冻结单任务case-01、源/产品/SDK、驱动/独立审计器、同接收方/预算。先无模型核对
   原始结构与实际图框：两重复候选确实等义、所有候选完整，左侧所需目标不在公开
   completion中泄漏。导航完成条件为公开目标URL，多个链接均可达，不能凭URL判定
   点击来源正确；独立审计必须逐步确认原绑定PNG、视觉选择ref/动作回执和左侧位置。
4. 一次双SDK假HTTP资格：Jev选择重复候选，经原守卫自然转图片；视觉按真实图框选择
   左侧链接，实际执行并导航。公开goal/候选不加入隐藏答案，不改模板、CSS或DOM，
   不强迫真实Jev控制输出。数据库只用于初始化和事后零写入审计。
5. 资格与审计通过后单次真实任务。沿用TypeSafe jev-1.14.0文字；自然分支由
   OpenRouter google/gemini-3.8-flash接收同状态/候选与绑定1280×720合成PNG。
   120秒、6动作、24观察、10万已记账token、全批8次SDK、视觉输出4096、重试0，
   金额未定价。token为宿主返回用量记账，不是提供方预留硬上界。未知效果/用量、
   未结预留、漂移或清理失败停止，不重跑、挑成功或更换策略。
6. 独立审计并保留真实失败。成功须实际Jev调用/不被接受的选择→同绑定图片→左侧
   正确链接派发→生产URL完成，且原始HTTP/DOM/最终HTML和零DB写入/清理均通过。
   若走Structure页签等错误入口，即使goal_verified也按任务失败；无图或猜选不算
   视觉接管完成。限定结论于一个空间任务，不作模型优劣、图片普遍必要或采用确认。
7. 研究/证据及计划记录更新，适用检查、项目独立审查和签名提交后结案。图标/颜色
   等其他界面特征、无候选定位/Box与确认性质量评估仍按backlog条件触发。
