# Jev动作级准入：保留完整候选的隔离原型

## 目标、范围与验收

承接[主计划](computer-use-jev-vision.md)和[96项分析](../../research/jev-calibration-route-analysis.md)。
当前任一重复/无标签候选会使整组转视觉；SQLite编辑步骤因此未调用Jev。
先验证动作级规则是否能保留可区分动作，同时拒绝歧义目标；不先假定同名导航等价，
不删除候选、不引入任务相关性分类器，也不把“文字身份唯一”当作模型答案正确。

本片仅为显式benchmark原型，复用原Controller、TaskRuntime、Jev及视觉选择链。
生产已冻结源码保持字节不变；benchmark内隔离谓词并以旧状态核对原全局判定，
复用原视觉分支，不添加生产factory模式、配置或默认开关。保留完整观察、候选、权限、参数、绑定、新鲜度、用量及效果核验。
原96数据只评规则覆盖，不回填Jev答案或估计扩大准入后的准确率/耗时。

## 调整后的后续顺序

本片验收范围仅为第1项；第2–4项由仍进行中的主计划承接。

1. **本片：动作级准入原型与反例验证。** 保留完整候选并标记重复/无标签目标；
   有文字可区分动作时可先提议，只有选中的目标通过文字可区分检查才接受。
   选择歧义/无标签目标或合法弃权时走原有视觉接管；全部不可区分、重复状态等
   已知视觉场景直接视觉。硬停止/未知用量不转成重试或额外模型调用。
2. **再次真实调用前：最小SDK故障记录。** 只补异常、请求完成、用量及停批原因，
   不扩成通用容错/自动重试；不续跑或重放第6槽未知调用。
3. **原型通过后：一次小批真实三臂开发测量。** 同批V/现有JT/动作级JT配对，
   固定视觉模型与其余条件，冻结新任务、顺序、终止门及数据范围。比较任务质量、
   错误动作、接管和完整耗时；发生退化即否决/调整，不自动扩大到3648槽。
   新原型与事件口径须重新冻结，现有真实runner/audit不自动支持新策略。
   本片不冻结正式N、不启动该测量，也不产生生产采用结论。
4. 图片Choice/Box作为独立能力切片推进，无需等待文字路由大规模确认；本片不测
   图片/Box模型排名或扩大图片接收方授权。
