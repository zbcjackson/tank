# Jev 真实应用图片增量对照

## 目标与范围

用户在计算器小样本完成后要求开始下一步：优先检查TextEdit临时文档的真实
格式工具栏，选择AX语义不足但仍有合法可执行候选的任务，对照同一Jev版本
的文本与图片路径。Qwen专项后置，生产默认保持不变。

成功标准：先以真实AX/截图证明任务与适配可行，冻结同一任务/候选/输入的
文本和图片对照；按计划分母记录完成、错误选择、弃权、耗时、用量和清理，
由独立读回及实际输入边界见证核验完成。小样本只给开发证据，不推导跨应用
可靠性。Box继续只读，覆盖小目标、目标不存在、重复目标和窗口位置变化。

## 执行步骤

1. 无模型调用探查新建TextEdit进程、临时文档的实际AX与绑定窗口截图。
   拒绝已有个人会话；关闭并清除自有进程/临时文件，保留原始观察与清理证据。
   不人为删除AX标签；若没有符合条件的任务，记录真实限制再选择可行应用，
   不把不完整结构或缺候选包装为可执行任务。
2. 根据探查冻结独立目标/验收、配对顺序、两臂对称预算、图片/坐标单位和原始
   证据。仅允许本切片新任务；上限26次真实请求、USD0.10、120秒/任务，
   后续按实际任务收窄，不挪用旧实验预留。不做未声明重试或按答案修正规则。
3. 优先复用已验证的TaskRuntime、原候选派发与SpendLedger，不扩展生产执行权。
   同版本Jev文本/图片比较必须保留相同公开语义、候选和目标；图是预声明差异。
   图内候选框同步映射；每项保留原始响应、实际动作、独立读回及清理。Box无
   执行器，结果不派发坐标动作。若只读判断与闭环任务不同，分别报告分母。
4. Tests：按TDD在已有视觉/原生测试文件中逐项扩展，覆盖离线准备不接触应用
   或客户端、冻结漂移拒绝、对称文本/图片输入、实际SDK/fake HTTP边界、全计划
   分母、失败/未知用量停止、独立成功判定、零Box输入和自有资源清理。已有
   chat.feature覆盖同域时复用，不新建重复feature。
5. 完成适用验证及最多三轮review-and-refactor，再执行已授权小规模真实运行，
   归档成功/失败/未运行的完整原始记录与结论。代码变化后旧冻结不得复用；
   文本失败或弃权保留在分母，不能被图片胜例筛选掉。

## 探查与具体方案（2026-10-19）

TextEdit1.20(415)富文本工具栏的bold/italic/underline/alignment均有描述，不能
把它当作缺标签胜例。完整描述观察因正文AXTextArea的AXDescription返回-25200
判为不完整；现有TextEdit标识符路径不查询该属性，可保持原完整性门进行正文fill。
不修改全局AX错误处理或提高遍历上限，不放宽原派发约束。

改用自然视觉语义：临时RTF中黑色标题及North/South两行，红蓝分配交换，任务为
只将红色行替换为DONE。当前AX观察包提供正文和工具栏信息，不提取正文逐字颜色；
两臂均保留实际描述观察（包括其不完整标志），不删标签，只有图片臂发送截图。
这测当前观察包的图片增量，不代表AX平台无法提供富文本属性。

两种红蓝分配×两个窗口位置×文本/图片两臂，共8个配对任务，每任务最多1次选择、
1次原生fill，之后独立核验正文；文本弃权和错误均保留。两种合法完整替换文本都
作为已知候选参数，模型只能选原候选，不能生成新文本。Controller保留私有目标
正文作完成核验；仅向模型投影公开意图和两个选项，不发送私有completion值。
原图/RTF及验收标签分离，反转私有标签不得改变公开请求。

另有两个新建原始RTF窗口进行6次只读Box：每窗口询问小italic按钮、不存在的
Export CSV按钮、多个alignment按钮。唯一目标中心与独立AX内部矩形比较；负例
和多目标分别计数量判断，永远不派发Box动作。计划合计14请求，USD0.10上限，
不做重试；所有任务、Box和未运行项分母冻结，完成率与只读判断分别报告。
输入候选顺序随位置反转，臂顺序交替。单步限额包含bind及一次fill；私有预期
正文只供Controller和独立读回核验。已知过期/不稳定画面或已知弃权保留为拒绝，
不放宽原帧门、不重试；未知用量/效果及未清理失败仍停止全批。代码和协议见
[TextEdit对照配方](../../../backend/benchmarks/computer_use/fixtures/jev-image-ablation/README.md)。

真实应用模拟HTTP预演首先发现光标连续动画：8项主任务均在稳定帧门前拒绝，
0主任务请求；6次模拟Box中4次也被原帧复核拒绝。保留该完整失败记录，不计
模型质量。随后仅选中黑色标题，独立确认选区和正文不变，四次截图hash一致，
目标红蓝行仍可见。将该固定准备动作对称用于两臂及Box，原像素检查不变。
完整预演仍遇到窗口右边缘的像素变化，保留捕获原图/scene与PNG哈希；不修改
像素门。最新模拟HTTP整批安全完成，12次模拟请求：图片模型模拟正确的3项实际
替换完成，1项帧前拒绝；文本3项模拟弃权、1项帧前拒绝，6项Box中1项帧后拒绝。
上述数字仅为接线/环境验证，不是Jev能力。真实评分须保留每臂4项任务、6项Box；
模型选择与任务完成分列，若报告模型对照子集，另列双方均实际调用的配对ID，
不能按成功答案挑选配对。
