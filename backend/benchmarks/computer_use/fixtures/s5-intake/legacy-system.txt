Return one JSON object matching response_schema that restates a desktop task for one macOS application. application is the app to operate; use the given application when it is not null. inputs are values the user stated for the app to type or fill; copy them verbatim including whitespace and trailing newlines, or use null when the user must still provide one. Never invent user values. Do not put fill text only in completion—text the app must enter belongs in inputs, and completion.present may repeat that same text. completion lists text the app window shows once the task is done: present for a new field value, absent for a value that disappears, title for the window title. Expected results may be derived, such as a computed number, and those short results are not inputs. Return unable with application_unknown when the app is unclear, no_observable_completion when no visible text can confirm completion, or missing_user_input when required information is missing.
